YKPili Windows 版 · 源码与第三方组件说明
=========================================

本程序（YKPili）是哔哩哔哩第三方客户端，使用 Rust + GPUI 编写。

对应源码
--------
- 版本：__APP_VERSION__
- 提交：__GIT_COMMIT__
- 获取方式：向发布者索取同版本源码，或从项目仓库对应 tag / commit 检出。
  按 GPLv2+ 要求，分发本二进制时须同时提供完整、可构建的对应源码。

随包第三方组件
--------------
1. libmpv / mpv（GPLv2+）
   - 来源：https://github.com/shinchiro/mpv-winbuild-cmake
   - 构建版本：20261021（mpv git e471496c56，x86_64）
   - 许可：GPLv2+（默认构建；含 GPL 版 FFmpeg）
   - 许可证全文：LICENSES/GPL-2.0.txt
   - 版权声明：LICENSES/MPV-Copyright.txt
   - mpv 源码：https://github.com/mpv-player/mpv
   - FFmpeg 源码：https://ffmpeg.org/

2. Rust 依赖
   - 完整清单见 app/Cargo.lock；各 crate 的许可证随其源码分发。

说明
----
本程序通过动态链接使用 libmpv-2.dll。由于所附 libmpv 为 GPL 构建，
整体分发需遵守 GPLv2+；如果你需要闭源分发，请自行替换为 LGPL 构建的
libmpv 与 LGPL 版 FFmpeg，并重新评估许可义务。
