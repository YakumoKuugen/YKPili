这一版修的是「占位」
  • 三个弹层从文档流里摘出来，改用 deferred + anchored 按互动行的 bounds 定位在窗口坐标：不顶开下方内容，且画在所有兄弟节点之后（GPUI 没有 z-index）。
  • 互动行几何由一层透明 canvas 在 prepaint 时写入；面板滚动时弹层跟着走，滚出可视区就不画。
  • 下方放不下时 anchored 自动翻到互动行上方，并留 16px 窗口边距。
顺带一起成立的细节
  • 卡片外是整窗点击层（occlude）：点任何别处都先收起弹层，这一次点击不再落到下面的按钮上。
  • 进出场：with_animation + opacity + 6px 位移，入场 ease_entrance、退场 ease_standard，150ms；退场期间内容按缓存的 kind 继续画，动画走完才摘掉。
  • 三个弹层共用同一档表面 surface_popover + 描边 + 阴影；收藏夹 368 宽，投币 / 分享 200 宽。
  • 侧栏收起、按 Esc、再点一次触发按钮，都会播退场动画后关闭。
