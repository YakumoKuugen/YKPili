## P1 · 验收与体感

- [x] **卡片 hover 近似（1.03）** 【文档 E-19】✅ 2026-10-24
  - 结果：外层 `.hover` 切 `surface_content_hover` / `shadow_card_hover` / `border_popover`；
    内层 `.group_hover` 用负 `inset(3px)` 放大，外层 `overflow_hidden` 裁剪。
  - 验证：悬停时背景/阴影切换；卡片点击仍能进入播放器。
  - 备注：GPUI 没有元素级 transform/transition，切换是即时的；封面 1.04 用整体 ~1.03 近似。

- [x] **hover 过渡动画（150ms）** 【核对】✅ 2026-10-24
  - 结果：共享 `hovered_card` / `leaving_card` / `hover_generation` 状态，
    `with_animation` 对当前卡做 0→1、对刚离开的卡做 1→0 的 `inset` 插值；
    其他旧卡不再一起重播。
  - 验证：进入/离开各触发一次 150ms 动画，只有对应卡片参与。
  - 备注：阴影/描边/背景仍是即时切换；`reduce_motion` 开启时动画自动退化为静态。

- [x] **减少动效 `reduce_motion`** 【文档 E-20】✅ 2026-10-24
  - 结果：启动时由 gpui-base 读一次；AppRoot 启动后每 2s 调
    `apply_system_reduce_motion`，值变化时 `cx.notify()`。
    `AnimationExt`（骨架/悬停等）在 reduce_motion 下自动渲染静态端值。
  - 验证：macOS 系统设置里切换「减弱动态效果」，2s 内日志
    `false -> true` / `true -> false`，动画停/恢复，无需重启。
  - 备注：Linux 由 gpui-base 跟随 portal 信号，不需要轮询。

- [x] **离线态（缓存回退 + 顶部条）** 【核对】✅ 2026-10-24
  - 结果：`FeedCache` 用 `CacheManager` 的包目录缓存最近 30 条推荐流；
    启动拉取失败或 `YK_OFFLINE=1` 时读缓存，顶部条显示
    「离线 · 缓存时间：X · N 条」；无缓存时展示占位内容并标注。
  - 验证：在线跑一次写缓存 → 离线启动读到 30 条；删缓存后离线启动显示占位内容。
  - 备注：离线是横切状态（顶部条 + 内容保持可读），没有新增 `PageState::Offline`。

- [ ] **离线态重试按钮** 【核对】
  - 现状：顶部条只提示，网络恢复后要重启应用。
  - 要做：后台重新拉取，成功后清离线标记、更新缓存与时间。
  - 规模：S–M。

- [ ] **弹幕描边 / 投影（E-14）** 【文档】
  - 现状：`danmaku_layer` 只画一次 `shape_line`，没有 stroke，也没有 shadow。
  - 要做：同一 `ShapedLine` 偏移多次绘制模拟 1px 描边，或裁决「去掉描边只留投影」并改规范。
  - 验收：亮色画面上白字可读；性能不掉帧。
  - 规模：S。

## P2 · 键盘与无障碍

- [ ] **键盘可达 + 焦点环** 【核对】
  - 现状：除了播放器输入框，代码里没有 `tab_stop` / `FocusHandle`；卡片、Dock、按钮都不能 Tab 到。
  - 要做：卡片/Dock/按钮补焦点句柄与 `tab_stop`；统一 `yk_focus_ring()`；浮层做焦点陷阱与归还。
  - 验收：Tab 顺序合理、焦点环可见、Enter 能进播放器、Esc 能退出浮层。
  - 规模：M–L。

- [ ] **`aria_label` / `role` 覆盖** 【文档 F.2 暂缓 / E-9】
  - 现状：`crates/` 里搜不到 `aria_label` 或 `.role(`；AccessKit 只会上报「有 id + 有 role」的节点。
  - 要做：图标按钮、封面卡片、播放器控制、信息面板 Tab 逐类补标签；
    按平台实测 `aria_label`/`role` 到 macOS/Windows 无障碍树的映射（E-9）。
  - 验收：VoiceOver 能读出「播放/暂停、进度、弹幕输入」等关键控件。
  - 规模：M。

- [ ] **动态字体接入（E-11）** 【文档】
  - 现状：字号全是 `text_size(px(n))`，没有平台倍率读取；macOS 也还没有应用内字号选项。
  - 要做：`text_scale() -> f32` 读一次并缓存；字号走 `.yk_text(n)`；
    iOS/Android/Windows/Linux 跟随系统，macOS 设置页给 100% / 115% / 130%。
  - 约束：行高一起乘；卡片高度重算；倍率夹在 0.85–1.3；触控热区/图标/描边不缩放。
  - 验收：四平台改系统字号后布局不破；macOS 应用内三档生效。
  - 规模：L。

- [ ] **`aria-live` 状态播报（E-13）** 【文档】
  - 现状：`Role::Status` 可用，但「节点文本变化是否触发 live announcement」未验证。
  - 要做：骨架→内容、离线→恢复、发送成功等场景实测；不行就用原生桥接。
  - 规模：S（验证）/ M（桥接）。
