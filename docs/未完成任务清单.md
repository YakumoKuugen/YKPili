- [x] **卡片点击播放** 【文档 04 / 06】✅ 2026-10-25
  - 结果：点卡片 → 读取 `bvid` → `/wbi/view` 取 cid/标题/时长 →
    `/wbi/playurl` 取流 → 选最高 DASH 视频 + 最高音轨 → libmpv 播放。
  - 音轨：DASH 视频/音频是两条 m4s；先 `loadfile` 视频，再 `audio-add <audio>`。
    不能用 `loadfile ... audio-file=...`（不是 per-file 选项，mpv 会报整数解析错误）。
  - CDN：优先 `backupUrl` 里的 `upos-sz-mirror*` 地址；`*.mcdn.bilivideo.cn`
    实测会只返回几百 KB（完整 m4s 的数十分之一），导致
    `ffmpeg: Stream ends prematurely at 0`。mpv 统一带 UA + B 站 Referer。
  - 登录：从 `session.json` 读 Cookie，登录态可拿 1080P；未登录走 480P。
  - 状态：取流期间显示「正在获取播放地址…」；失败显示具体错误；
    `PlayerState.position/duration` 跟随 mpv 的 `time-pos` 与 `timelength`。
  - 控制：播放/暂停已通过渲染线程命令接 `mpv set pause yes/no`；
    倍速/音量/进度拖动仍未接。

- [x] **播放浮窗化 + 关闭** 【文档 06】✅ 2026-10-25
  - 形态：顶栏下方 16px 的 600 高浮窗，圆角 12 + `shadow_glass_modal`；
    播放时分类条保留 54px 布局、仅视觉隐藏（避免首页上下跳），

  - 关闭：点击浮窗外侧（顶栏下方、浮窗之外的页面区域）立即关闭；顶栏保持可用。
    遮罩带极低透明度背景保证可命中，点击时 `stop_propagation`；卡片 on_click
    在 `playing.is_some()` 时直接忽略，避免关闭浮窗的同一拍又打开下层封面。
  - Hover：打开浮窗时清空 `hovered_card/leaving_card`；`on_hover` 在
    `playing.is_some()` 时直接返回，避免鼠标停在顶栏与浮窗的缝隙里时，
    下层封面仍显示 hover 操作按钮/缩放。
  - Esc：第一次在**顶栏右上角、浮窗/视频之外**显示「再次按 Esc 关闭」提示，
    5 秒自动收回；期间第二次 Esc 才关闭。收回后下次 Esc 重新从「第一次」算起。
    根元素 `track_focus`，打开时把焦点交给浮窗；提示代际号防止旧定时器误关新提示。
  - 收尾：关闭只置 `close_player_requested`，下一帧 AppRoot render 再移除实体，
    避免在 PlayerView 自己的回调里析构；PlayerView drop 后渲染线程停止。
  - 首帧：取帧循环在 worker 创建后的**同一帧**启动；不能等下一次 render，
    否则窗口未激活/被遮挡时会「只有声音、点一下播放器才出画」。
  - 入场：点击时从卡片实际封面 bounds 展开到浮窗目标框（左/右 16、顶 80、高 600）。
    封面 bounds 由卡片内容层 `on_children_prepainted` 捕获（含 hover 缩放），
    页面原点由根 `canvas` 记录；快照在收起分类条前冻结。
    入场 280ms / `EaseEntrance`（`cubic-bezier(0.22,0.61,0.36,1.08)`）：
    单段曲线起手与 EaseStandard 一致，尾部约 0.9% 过冲后自然回落，
    没有两段缓动在 300ms 处换速度造成的顿点。
    过渡期只画封面海报，结束后才挂播放器内容，避免控制栏塞进小盒、
    `deferred` 面板按钮越界。动画 id 用 `entrance_generation` 稳定，不受视频 60fps 重绘影响；
    `reduce_motion` 时由 AnimationExt 直接给端值。
    关闭时先恢复分类条/网格，再用 260ms 反向缩回封面快照；缩回期只保留当前视频帧
    （无帧用封面海报），完成后才移除 PlayerView。
